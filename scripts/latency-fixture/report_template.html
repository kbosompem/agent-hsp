How this was measured

Each recording was converted to 16 kHz mono and replayed through the app's own segmenter, Whisper small.en speech model and verse parser, with the same rules the console uses (a verse is not repeated within 3 minutes). "After" re-runs verse detection on the same transcripts with this round's parser fixes.

The answer key comes from a slower, larger speech model (Whisper large-v3-turbo) on the full recording. Reviewers then read every transcript and marked each verse the preacher cited, correcting misheard book names from context. A full reference counts as caught if the right verse appears between 5 seconds before and 30 seconds after it is spoken, or if it was already on screen from the previous 3 minutes. A wrong verse is one no citation within a minute explains.

One recording (Proton 1, Feb 2008) was dropped: it is clipped noise with no intelligible speech.
